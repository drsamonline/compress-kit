What it gives you

gzip / deflate

Standard formats, produced and read by the platform — so anything else can open them.

deflate-raw

Smallest payload when you control both ends and don't need a container around it.

String ⇄ base64

One call to compress or expand text, returning base64 you can paste anywhere.

No library

Compression Streams are built in. This is the wrapper, not a reimplementation.

The API

// bytes in, bytes out
const packed   = await C.gzip(bytes);
const restored = await C.gunzip(packed);

// the raw pair, when both ends are yours
await C.deflateRaw(bytes);   // and C.inflateRaw back

// the self-test is a Node script, not a button on this page:
//   node test-node.js   — every format, round-tripped

// text in, base64 out
const b64 = await C.compressString(text, 'gzip');
await C.decompressString(b64, 'gzip');
